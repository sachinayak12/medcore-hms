# MedCore HMS

> Enterprise Hospital Management System built with Java Microservices & Angular.

## Tech Stack

- Java 21
- Spring Boot 3.5
- Spring Cloud Gateway
- Eureka
- PostgreSQL
- Kafka
- Redis
- Angular 20
- Docker

## Architecture

This project follows a **Microservices Architecture** with Database-per-Service.
